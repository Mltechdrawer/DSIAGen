# Proyecto Aula Abierta: instrucciones del informe

**Documento de ejemplo ficticio · ID: AA-INST-v2 · Versión vigente: 2 · Fecha ficticia: septiembre de 2026.** Para uso exclusivo de la Actividad 3.

## 1. Ámbito

Estas instrucciones se aplican al informe del proyecto Aula Abierta de la edición 2026–2027. Sustituyen las instrucciones de la edición anterior.

## 2. Informe escrito

El informe tendrá un máximo de **seis páginas de contenido**. Se entregará en **PDF**. La portada y las referencias bibliográficas no cuentan dentro de esas seis páginas. Se permite añadir un anexo de hasta **dos páginas**, destinado únicamente a materiales de apoyo.

## 3. Presentación

Cada equipo dispondrá de **diez minutos** para presentar su trabajo. Se puede utilizar una presentación visual, pero estas instrucciones no establecen si debe entregarse con antelación.

## 4. Cambios

Si el equipo necesita modificar el título del proyecto, debe solicitarlo a la coordinación. La solicitud no implica aprobación automática.

## 5. Información no incluida

Este documento **no fija una fecha de entrega**. La coordinación comunicará el calendario mediante un aviso posterior.
