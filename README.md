# Diseño de Sistemas de Inteligencia Artificial Generativa

Estructura inicial del sitio docente en MkDocs Material. Las páginas de los temas y las actividades son fichas de trabajo para desarrollar posteriormente; no contienen todavía materiales docentes completos ni criterios definitivos de evaluación.

## Vista previa

```bash
pip install -r requirements.txt
mkdocs serve
```

## Imagen de portada y colores

La portada ya muestra `docs/assets/images/cdeiaa.png`, incluida en este paquete. El tema usa verde bosque apagado (`#2F6655`) en la cabecera y verde oscuro (`#285A4A`) como acento. Los colores se configuran en `mkdocs.yml` y `docs/assets/stylesheets/extra.css`.

## Dedicación

Las tablas distribuyen de forma **orientativa** las 75 horas totales de la ficha entre los tres bloques y la evaluación. El detalle de horas de trabajo del estudiante en la ficha suma 45 horas, aunque declara 75 horas en total; por ello, esta distribución didáctica debe validarse antes de publicarla como planificación definitiva.

El proyecto final cuenta dentro del Bloque III y aparece también como acceso independiente en la navegación. La evaluación y el cierre se contabilizan una sola vez.
